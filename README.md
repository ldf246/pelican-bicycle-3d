# 🚲 Pelican on a Bicycle · 鹈鹕骑自行车（3D）

一只白鹈鹕绕着湖边环形公路骑自行车的实时 3D 场景，纯前端，零构建，直接用浏览器打开即可。

**在线体验：** https://ldf246.github.io/pelican-bicycle-3d/

## 亮点
- **程序化建模**：鹈鹕（S 形脖子、长喙、会晃动的喉囊、羽冠）与自行车（辐条、链条、牙盘、车铃、车篮里的鱼）全部由代码生成，无外部模型。
- **两段骨骼 IK**：鹈鹕的腿实时追踪踏板，翅膀握住会转向的车把。
- **物理感**：按速度计算过弯压弯角度、车轮/牙盘按齿比转动、踩踏起伏。
- **环境**：着色器渐变天空、实时软阴影、湖面涟漪、睡莲、低多边形树林/花海/雪山、云、飞鸟、路灯。
- **昼夜切换**：星空、车头灯（SpotLight）、尾灯、路灯平滑亮起。
- **5 种镜头**：追随 / 自由 / 侧拍 / 电影环绕 / 鹈鹕第一视角。
- **Web Audio 合成音效**：车铃（多泛音衰减）、冲刺风声、鹈鹕叫声，无音频文件。
- **互动**：点击鹈鹕喉囊鼓起；冲刺时羽毛飞散、FOV 拉伸；HUD 显示速度、里程、圈数、踏频；一键截图。

## 操作
| 按键 | 功能 |
| --- | --- |
| Space | 按铃 |
| B | 冲刺 |
| C | 切换视角 |
| N | 昼夜切换 |
| P | 暂停 |
| ↑ / ↓ | 调速 |

鼠标拖动旋转（自由视角下）、滚轮缩放。

## 技术栈
Three.js r160（CDN ES Module）· WebGL · Web Audio API · 原生 HTML/CSS（毛玻璃 UI）

## 本地运行
```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```
